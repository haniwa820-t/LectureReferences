# Zotero導入とデモ（Mac）

【追加】公式ページを2026-10-06確認。発表当日に全員がインストールする必要はない。

1. https://www.zotero.org/support/installation から本体とConnectorの案内を開く。
2. Macではdmgを開いて本体をApplicationsへ配置する。
3. ブラウザ用Connectorを用意し、本体を起動する。
4. https://doi.org/10.11435/gengo.139.0_57 を開いて書誌を登録する。
5. 著者3名・2011年・139巻・57–84頁・DOIを確認する。
6. うまく登録できなければdocs/exercises/linguistics-demo.risを使う。
7. Word連携は https://www.zotero.org/support/word_processor_plugin_usage を確認する。

デモの実施前チェック：Connectorのアイコン、Wordプラグイン、姓名順、引用ページ、スタイル変更後の出力。未実施の手順を実施済みと記録しない。

端末なしの参加：投影で同じ情報を探す。通信不可なら印刷した書誌カードを使う。
